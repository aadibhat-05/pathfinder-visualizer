Pathfinder:

A simple pathfinding visualizer made with HTML, CSS and JavaScript. It shows how different algorithms search for a path between two points while avoiding obstacles.

Algorithms:
  BFS — Finds the shortest path in an unweighted grid.
  DFS — Explores one branch at a time before backtracking.
  Dijkstra's Algorithm — Finds the shortest path based on distance.
  A* — Uses distance and a heuristic to find a path efficiently.
  Greedy Best-First Search — Prioritizes nodes closer to the destination.
Features: 
  Draw walls and move the start and end points.
  Generate random mazes.
  Control the animation speed.
  Compare all five algorithms side by side.
  View explored nodes, path length and execution time.
  Running the project

No installation is needed. Clone the repository and open index.html in your browser.
